## 2. Project 2: `exam-invigilation-dsa-app` / `InvigiMatrix` (Combinatorial Optimization)

- **Repository**: [github.com/hrlpavan/exam-invigilation-dsa-app](https://github.com/hrlpavan/exam-invigilation-dsa-app)
- **Languages & Frameworks**: JavaScript (ES6+), Node.js native (`node:http`, `node:fs`), SQLite 3 (`better-sqlite3`), Tailwind CSS.
- **Key Engineering Achievements**:
  1. **Constraint Satisfaction Problem (CSP) Backtracking Solver**: Resolves NP-hard multi-variable scheduling assigning faculties, rooms, subjects, and dates with zero collision.
  2. **K-Means Clustering ($k=3$)**: Dynamically groups and partitions cohort admissions data.
  3. **Bayesian Lateral-Entry Classifier**: Distinguishes regular vs. lateral entry students using prior admission distribution curves.
  4. **Zero-Framework Architecture**: High-throughput REST API with no Express/Fastify dependencies, utilizing raw Node.js HTTP primitives and ACID-compliant prepared SQLite transactions.
  5. **Custom Sliding Window Token Bucket Middleware**: Protects AI endpoints against Denial of Service (DoS) attacks.
  6. **Apple Liquid Glass UI**: Frosted subpixel blurs, dynamic pill navigation, and HTML5 2D Canvas A4 matrix export engines.
